# planilha_imposto_renda
Organizador de Declaração de Imposto de Renda

📊 Organizador de Imposto de Renda (Fiscal / Tributária)

Este repositório contém a planilha `organizador_imposto_renda.xlsx`, desenvolvida para organizar, estruturar e analisar dados fiscais e tributários. O objetivo deste projeto é fornecer uma visão clara e sistematizada dos cálculos, obrigações e lançamentos fiscais.

## 🔍 Visão Geral

A planilha foi elaborada para facilitar a apuração fiscal. Ela serve como uma ferramenta prática para profissionais de contabilidade, tax e finanças que buscam maior precisão na conferência de dados tributários.

## 📂 Estrutura do Arquivo

O arquivo `organizador_imposto_renda.xlsx` está organizado nas seguintes seções/abas:

| Aba / Seção | Descrição | 
| ----- | ----- | 
| **Titular** | Preenchimento de informações sobre o titular. | 
| **Informes** | Cadastro dos extratos bancários e cálculo automático do valor total. | 
| **Notas** | Notas bancárias ou extrato de holerites. | 

## 💻 Requisitos de Uso

Para abrir e utilizar a planilha sem perda de formatação ou funcionalidades, recomenda-se:

* **Microsoft Excel** 2016 ou superior (desktop ou Web)

* **Google Planilhas** (*Google Sheets*)

* **LibreOffice Calc** (v7.0+)

## 🚀 Como Utilizar

1. **Clonar o Repositório:**

   ```
   git clone https://github.com/osvaldhenrique/planilha_imposto_renda.git
   
   
   ```

2. **Abrir o Arquivo:**
   Navegue até a pasta do projeto e abra o arquivo `organizador_imposto_renda.xlsx` no software de sua preferência.

3. **Inserir os Dados:**
   Preencha os campos da aba de entrada/base de dados conforme as especificações fiscais.
